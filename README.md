# Controle de Gastos

Sistema simples em Python e SQLite para controle financeiro pessoal.

## 🚀 Funcionalidades
- ✅ Adicionar gasto (descrição, valor, categoria, data)
- 📊 Lista todos os gastos
- 🗑️ Exclui gastos por id
- 💾 Salva em um banco de dados local

## 🛠️ Tecnologias

Python + SQLite3

## 🧑‍💻 Como rodar

**Para quem não tem Python**
- Instale o arquivi.exe em Release
- Crie uma pasta chamada 'Gastos' em sua Área de Trabalho
- Rode o programa

**Para quem tem Python configurado**

```bash
python controle_gastos.py
